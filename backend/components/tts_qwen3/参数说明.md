# tts_qwen3 参数说明

`backend/components/tts_qwen3/config.json` 是本地 Qwen3-TTS 引擎的组件层配置（JSON 无注释，本文档就是它的注释）。**改任何字段后需重启**（`stop_web.sh && start_web.sh`）。运行说明见同目录 `README.md`。

Qwen3 是**本地可选** provider（当前骰子 manifest 未引用，切换方式见根目录 `TTS配置与切换指南.md`）。

```json
{
  "runtime": {
    "kind": "local",
    "root": "tts/qwen3-tts",
    "model_dir": "qwen3-tts-0.6b",
    "host": "127.0.0.1",
    "port": 18080,
    "base_url": "http://127.0.0.1:18080"
  },
  "voice": {
    "default": "default",
    "speaker_file": "anke.spk.bin"
  },
  "generation": {
    "timeout_seconds": 120,
    "speed": 1.0,
    "chunk_chars": 24
  }
}
```

## 字段说明

### runtime（本地 llama-server）

| 字段 | 当前值 | 说明 |
|---|---|---|
| `kind` | `local` | 本地引擎（被 manifest 引用时 `start_web.sh` 自动拉起 llama-server） |
| `root` | `tts/qwen3-tts` | runtime 根目录，**仓库相对路径**（模型 GGUF/ONNX 不入库，按该目录 .gitignore 留在板上） |
| `model_dir` | `qwen3-tts-0.6b` | 模型目录，**相对 root** |
| `host` / `port` / `base_url` | 127.0.0.1 / 18080 | llama-server 监听地址，**校验强制 loopback** |

### voice（音色）

| 字段 | 当前值 | 说明 |
|---|---|---|
| `default` | `default` | 默认音色名（请求未指定 voice 时使用） |
| `speaker_file` | `anke.spk.bin` | speaker 嵌入文件，**相对 root**（`.bin` 不入库） |

### generation（生成参数）

| 字段 | 当前值 | 说明 |
|---|---|---|
| `timeout_seconds` | `120` | 单次合成请求超时 |
| `speed` | `1.0` | 默认语速，范围 **0.25 ~ 4.0**（manifest 台词级 speed 覆盖此默认） |
| `chunk_chars` | `24` | 文本切块字符数（按标点切块后超长段落再按此上限切；**最小 8**）。块越小首包越快、块越大韵律越连贯 |

## 其他须知

- 合成按标点切分段落、逐段出帧（chunk 级流式）。
- 与 MOSS 的取舍：支持语速和 speaker 嵌入音色；首次启动要加载大模型，冷启动比 MOSS 慢。
