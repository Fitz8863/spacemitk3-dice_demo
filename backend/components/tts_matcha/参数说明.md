# tts_matcha 参数说明

组件目录：`backend/components/tts_matcha/`
引擎目录：`tts/matcha-tts/`（源码、板端资产与协议文档见该目录 README）

## 职责

把常驻 `matcha_tts_service` 子进程适配成 Dice Arena 的本地 TTS provider：
句级流式合成（每句一帧完整 WAV，16 kHz / mono / 16-bit）、启动预热、
崩溃自动重启、随后端进程退出。无 lifecycle 脚本、无 HTTP 中转——
provider 直接持有子进程的 stdio。

## 本地引擎契约

- 全局配置 `backend/config.json` 的 `providers.tts_local` 指向本组件后，
  本次进程运行期间唯一可用本地 TTS 就是它（换引擎 = 停服改配置重启）。
- 后端启动时调用 `prewarm()`：同步拉起子进程并等待预热完成；
  预热失败 = 启动失败，后端拒绝服务。
- 后端退出时经 `_shutdown_runtime_components` 调用 `shutdown()` 收掉子进程；
  子进程另有 getppid 看门狗，后端被 SIGKILL 后 2 秒内自行退出。

## config.json 字段

```json
{
  "schema_version": 1,
  "runtime": {
    "kind": "local",              // 固定 local（子进程引擎）
    "root": "tts/matcha-tts",     // 引擎目录（项目相对；下述路径都相对它）
    "binary": "build-cpp/matcha_tts_service",
    "model_dir": "matcha-model",  // 板端资产（.gitignore）
    "sherpa_lib_dir": "runtime/sherpa_onnx/lib",  // 板端资产
    "ep_threads": 2,              // SpacemiT EP 工作线程数
    "ep_affinity": "8;9",        // EP 线程绑核（数量必须等于 ep_threads）
    "enable_affinity": true,      // false 时不绑核
    "start_timeout_seconds": 60,  // 拉起+预热的最长等待（超时=启动失败）
    "terminate_grace_seconds": 5, // 停子进程时先 EOF 等待的优雅期
    "request_timeout_seconds": 120 // 单条合成请求的兜底超时
  },
  "startup": {
    "warmup_text": "你好。"        // 预热文本（进入 ready 前的一次合成）
  },
  "generation": {
    "chunk_target": 40,           // 切句目标长度（UTF-8 字符），越小首帧越快
    "chunk_max": 90               // 单句硬上限，超过强制切分
  },
  "voice": {
    "speaker_id": 0               // 单说话人模型，只允许 0
  }
}
```

## 请求语义（voice / speed）

- **voice**：音色即 id，当前模型只有 `0`。请求层 `"default"` 与 `"0"` 都映射
  到 sid 0；其他值报参数错误（单说话人模型，换音色需换模型）。
- **speed**：语速倍率，真实透传给引擎（0.25–4.0 由基类钳位），
  `1.2` 更快、`0.8` 更慢。
- 文本中的制表符/换行会被折叠成空格（请求协议按行按制表符分帧）。

## 调参建议

- 台词首帧出声慢 → 调小 `chunk_target`（骰子台词 28–40 字符较合适）。
- 想进一步压低合成耗时 → `ep_threads` 提到 4 并给 4 个核
  （注意与 YOLO EP 的 14;15、ASR 的 X100 0-7 错开）。
- 换模型后必须同步 `runtime.model_dir` 内的文件名约定
  （model-steps-3.q.onnx / vocos-16khz-univ.q.onnx 等，见引擎 README）。
